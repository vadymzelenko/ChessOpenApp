# packs/ — исходники дебютов

Каждый дебют — папка `packs/<id>/` (ТЗ §3):

| Файл         | Что внутри                                                          |
| ------------ | ------------------------------------------------------------------- |
| `meta.json`  | Название, сторона, ECO, стиль, сложность, цвет, источники           |
| `ideas.json` | Библиотека идей: `id`, `title`, `text` (3–8 предложений), диаграмма |
| `*.pgn`      | Экспорт студии Lichess (все главы). Можно несколько файлов          |

Папки с `_` в начале (например `_example`) — образцы: проверяются, но в приложение не попадают.

## Команды

```bash
npm run pack:build -- london   # собрать пакет → apps/mobile/assets/packs/london.json
npm run pack:check             # проверить все пакеты без записи
npm run pack:schema            # JSON Schema формата → packs/opening-pack.schema.json
```

## Как писать в студии Lichess

- **Глава = глава курса.** Каждая ветка (вариант) = отдельная линия.
- Главы с названием «Ловушки…» превращаются в ловушки, «Партия…» — в образцовые партии.
- Комментарий пишется **после хода**, отвечает на «зачем», максимум 2 предложения.
- Стрелки и подсветка клеток из студии сохраняются (`[%cal …]`, `[%csl …]`).
- Дополнительные теги в комментарии:

| Тег                  | Значение                                                          |
| -------------------- | ----------------------------------------------------------------- |
| `[%idea id1,id2]`    | Ссылка на идеи из `ideas.json`                                    |
| `[%level advanced]`  | Уровень линии: `base` / `advanced` / `deep` (по умолчанию `base`) |
| `[%status reviewed]` | `draft` / `engine-checked` / `reviewed` (⭐ только у `reviewed`)  |
| `[%trap]`            | Ход-ловушка (`[%trap against]` — ловушка против нас)              |
| `[%line my-id]`      | Свой id линии (иначе генерируется из ходов)                       |
| `[%title Название]`  | Название линии или ловушки                                        |

Уровень, статус, id и название относятся ко всем линиям, проходящим через этот ход.

Сборка падает с понятной ошибкой, если: ход нелегален, идея не найдена, линии дублируются,
у ловушки нет пометки или объяснения. Предупреждение — если в одной позиции курс даёт два
разных хода за нашу сторону (это допустимо, если так задумано: «агрессивно» / «спокойно»).
