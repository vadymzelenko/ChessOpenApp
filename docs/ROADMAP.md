Экран «Доска» — анализ с деревом вариантов (`GameTree` в core): ход из любой позиции создаёт ветку, ветки можно сделать главной или удалить; дерево в стиле Lichess с линиями-связками; горячие клавиши в web (← → ↑ ↓ Home End F).

### Доработки по отзыву (UI/UX)

- Перетаскивание: фигура двигается без «клетки» (убрана тень/elevation, цель — тонкая рамка).
- 7 открытых наборов фигур (Celtic, Chessnut, Spatial, Fantasy, Papercut, Totoy, RhosGFX) — лицензии MIT / Apache-2.0 / CC BY / CC0, см. `packages/ui/src/board/pieceSets/LICENSES.md`; GPL/NC-наборы исключены.
- Шрифт Manrope (OFL), иконки lucide (ISC).
- Переход между вкладками — полноширинный слайдер без вспышки.
- Перетаскивание: убрана и рамка целевой клетки — за пальцем/мышью двигается только фигура.
- Новый дизайн: плитки (`Tile`) с иконками, градиентами и водяными знаками, анимация появления плиток со сдвигом (`Appear`), пружинный отклик на нажатие (`PressableScale`), своя панель вкладок со скользящей «таблеткой», крупные заголовки экранов вместо системных.
